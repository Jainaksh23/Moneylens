# MoneyLens Financial Education Knowledge Base

This directory contains approved, curated financial-education markdown documents for the RAG (Retrieval-Augmented Generation) system.

### Principles:
1. **Educational & Decision Support Only**: No regulated investment advice, stock picking, or tax consultancy.
2. **Contextual Grounding**: Every document provides neutral, educational context on Indian personal finance topics (e.g., Emergency funds, RBI guidelines, SEBI basics, Debt management, Inflation, Tax slabs under Old vs New regime, compounding principles).
3. **Traceability**: All answers generated by the AI assistant cite these approved documents alongside the user's computed financial metrics.
